# Infrastructure Engineering Lab

Hands-on infrastructure engineering projects covering Linux administration, virtualization, networking, automation, cloud infrastructure, and identity and access management (IAM).

## Objective

Develop practical infrastructure engineering skills through repeatable deployments, controlled failure simulations, troubleshooting, and technical documentation.

## Lab Environment

- Proxmox VE
- Debian Linux
- Linux Containers (LXC)
- Ansible
- SSH
- Additional technologies introduced in future projects

## Engineering Methodology

1. Understand the technology.
2. Design and implement a solution.
3. Validate its functionality.
4. Simulate failures in an isolated environment.
5. Recover and verify the desired state.
6. Document findings and limitations.

## Security

All published configurations are sanitized. Private keys, credentials, and environment-specific inventories are excluded.

## Roadmap

Future projects will explore networking, firewall configuration, backup and recovery, infrastructure monitoring, cloud automation, and IAM.
